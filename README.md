# 🚌 Campus Bus — Dr. Hari Singh Gour University (DHSGSU), Sagar

Ek ultra-premium, modern **Light Mode Single Page Website** jo Dr. Hari Singh Gour Vishwavidyalaya, Sagar ke 1300+ acre campus me chalne wali buses ki live tracking karne aur students/faculty ko direct **55 MB APK** download karwane ke liye design ki gayi hai.

## 🌟 App & Website Features

1. **Live GPS Bus Tracking (DHSGSU Campus)**:
   - University campus me chalne wali sabhi buses ki live location aur speed.
   - Patharia Hills campus ke sabhi routes ka visual live map representation.

2. **Pickup Point Selection (Stops)**:
   - Students apna pickup stop (Central Library, Main Gate, Tagore Girls Hostel, C.V. Raman Boys Hostel, Science Block, Engineering Dept, Health Centre) select kar sakte hain.
   - Stop par bus aane se pehle **5-Minute Arrival Alert** notification.

3. **55.0 MB Optimized APK**:
   - University campus ke sabhi offline maps aur stops ka cached database.
   - Low mobile network areas me bhi smooth chalne ke liye specially optimized.

4. **Step-by-Step 6-Kadam Phone Installation Guide (Hindi)**:
   - *Kadam 1*: 55 MB APK file download shuru karna.
   - *Kadam 2*: Chrome me "File might be harmful" aane par "Download anyway" dabana (University Safe Certified).
   - *Kadam 3*: Notification bar se `CampusBus-DHSGSU.apk` par tap karna.
   - *Kadam 4*: Android Settings me jakar "Allow from this source" switch ko ON karna.
   - *Kadam 5*: Package Installer screen par "Install" dabana.
   - *Kadam 6*: "Open" karke apna campus pickup point select karna!
   - Samsung, Xiaomi/Redmi (10s risk countdown), Realme/Oppo/Vivo aur OnePlus ke brand-specific tips.

5. **100% Mobile Responsive Light Mode**:
   - Modern glassmorphism, clean off-white background with subtle glows, and touch-friendly mobile design.
